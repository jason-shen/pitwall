工作流程

简报，构建，审查，发布。

01

写简报。

从专为智能体工作准备的模板开始：新功能、修 bug、重构、界面打磨、技术探索。用你自己的话写下需求，然后点 ✦ 用 AI 完成。Claude 会读你的代码，把问题、涉及的文件、步骤和待定问题一一补全，你可以看着它写。

04

像负责人一样审查，而不是当打字员。

安全

护栏只会收紧。

pitwall 从不凭自己对 shell 的理解悄悄放行命令。你的规则拒绝的，它就拒绝；需要看一眼的，它排队等你；其余的交给智能体自己的确认提示。

会修改 add-metrics 想运行 npm install --save-dev jest && cargo test 查看批准 ⌘⇧Y拒绝 ⌘⇧R
✕ 已拒绝cargo test && rm -rf ~每一部分单独判断，最严格的结果说了算

拒绝规则处处有效

藏在 sudo、FOO=1、git -C dir 后面，或者写在 bash -c '…' 里，都一样拦得住。

每一步之前都有快照

每个智能体都有一条影子 git 时间线。对比任意一步，回退到那里，也能撤销回退。

#5#4#3 ↺#2#1

你的文字不会丢

智能体改写了你正打开的文件？之前的版本按一下 ⌘Z 就回来。

智能体协作

会互相沟通的智能体。

每个 pitwall 终端的 PATH 里都有 pitwall 命令。智能体可以列出、发消息、等待和读取彼此，所以负责构建的可以直接交给负责审查的，不用你在中间传话。

builder
$ pitwall agents
  ● builder    working   ~/code/app
  ● reviewer   idle      ~/code/app
$ pitwall tell reviewer "看看登录的修复，然后告诉我"
  sent to reviewer
$ pitwall wait reviewer
$ pitwall read reviewer -n 4
  [message from agent reviewer] 看起来没问题。cookie 的
  标志位有两处小意见，已经留言了。

你的 ssh，你的配置

会话用的就是你自己的 ssh，所以 ProxyJump 和 ssh-agent 都照常工作。~/.ssh/config 里的主机会自动出现；其他的在应用里添加。

一条命令，所有机器

运行… 把一条命令发给一组服务器，并显示每台的退出码和输出。会改动东西的命令会先问你。

服务器上的智能体也看得到

服务器上运行的 claude 会从屏幕上识别出来，以 build box · claude 列出，并标上“远程”。

底层

它也是一个真正的终端。

由 GPU 绘制。智能体跑在它们自己的 TUI 里，你的 shell、vim 和 lazygit 就平铺在旁边。

关掉窗口，什么都不会停。

后台的守护进程管理着每一个终端。退出应用，智能体照样工作。重启电脑，它们会回到各自的文件夹，接着之前的会话继续。

标签页和平铺

拆分、拖动、交换、调整卡片大小。还能把输入广播到所有卡片。

内置 Git

lazygit 的布局和按键：暂存代码块、提交、切换分支，都在窗口里完成。

用你的编辑器，或者我们的

内置编辑器会实时重新加载，也可以用 nvim、helix、VS Code、Cursor、Zed。

回滚记录不会丢

重启后依然保留。把卡片拉窄，文字会重新换行，而不是被截断。

按键都好用

支持 kitty 键盘协议，所以在 Claude Code 和 Codex 里 Shift+Return 就是换行。

多语言

支持中文、日文和韩文输入法。界面有七种语言。

API 密钥，锁好了

令牌用 AES-256-GCM 加密，由单独的密码保护。每次显示或复制都要确认；剪贴板会自动清空。
